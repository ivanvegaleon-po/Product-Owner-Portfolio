# Product Owner Portfolio

Portafolio de proyectos desarrollados durante mi formación y certificación como Product Owner. Documenta la aplicación de visión de producto, propuesta de valor, análisis de stakeholders, priorización, métricas y mejora continua.

## Caso de estudio destacado

### EvoluTech — Plataforma de visibilidad operativa

EvoluTech es una propuesta de plataforma digital de visibilidad operativa y relacionamiento inteligente para una empresa manufacturera. Integra información de planta, mantenimiento, logística, ventas, servicio y clientes para convertir datos dispersos en decisiones más rápidas, trazables y orientadas al valor.

**Competencias aplicadas:** visión de producto, propuesta de valor, análisis de stakeholders, priorización de iniciativas, métricas de éxito y transformación digital.
